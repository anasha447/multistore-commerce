# ADR-0013: Java 21 only

Status: accepted, 24 November 2026

## Context

The owner wants Java 21, the long-term release on the development machine.

## Decision

Compile and run on Java 21 everywhere (`release` 21, `eclipse-temurin:21`). The build refuses another major version. Virtual threads stay off: on Java 21 they can pin a carrier thread inside `synchronized` code and native calls such as image encoding, and with a 10-connection pool they bring nothing. 50 platform threads instead.

## Consequences

Reopen virtual threads if the Java version moves past 24, where most of that pinning was removed.
