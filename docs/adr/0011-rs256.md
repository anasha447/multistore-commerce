# ADR-0011: Keep RS256 tokens

Status: accepted, 24 November 2026

## Context

One app both signs and checks tokens, so a shared secret would work.

## Decision

Keep RS256, keys from mounted files, one key pair per store. One public key at a time.

## Consequences

Reuses tested code; a future separate service can verify without being able to sign. Rotation is replacing both files: access tokens signed with the old key answer 401, the storefront refreshes by itself (refresh tokens are not signed), nobody is signed out.
